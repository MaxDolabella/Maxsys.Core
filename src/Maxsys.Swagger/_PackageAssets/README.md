**Maxsys.Swagger** complementa o pacote **Maxsys.Web** com configurações de *Swagger/OpenAPI* (Swashbuckle): filtros para documentar enums, parâmetros `[FromJson]`, identificadores de endpoint (`ActionIdentifier`) e limpeza de documentação XML.

## :dart: Target
`.NET 10`
